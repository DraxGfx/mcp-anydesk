## Cambios

### v3.5.0 — get_version + version en get_system_status
- Nuevo tool `get_version` — retorna version del MCP server
- `get_system_status` ahora incluye `server_version` en la respuesta
- Bump a 3.5.0

### v3.5.1 — Screenshot optimizado + send_cancel documentado
- `capture_screenshot` ya NO devuelve base64 por defecto (causaba 2-3 min de procesamiento en Claude Desktop)
- Nuevo parametro `return_base64=False` — solo si se pide explicitamente
- Screenshots se guardan a disco automaticamente, response solo tiene metadata
- `send_cancel` cambiado: solo enfoca la ventana, el operador presiona Ctrl+C manualmente
- Eliminado todo codigo de VK combos (`_send_vk_combo`, VK constants, `MapVirtualKeyW`)
- Docstrings actualizados (write_to_anydesk, capture_screenshot, send_cancel)
- SYSTEM_PROMPT.md actualizado con nuevos tools y limitacion de Ctrl+C
- CLAUDE.md actualizado con arquitectura UNICODE

### Fix critico: pip install en venv
- Claude Desktop usa `.venv/Scripts/python.exe`
- `pip install .` global NO afecta al MCP — debe ser `.venv/Scripts/pip.exe install -e .`
- Documentado en CLAUDE.md y MEMORY.md

## Hallazgos

- **KEYEVENTF_UNICODE confirmado funcional con AnyDesk** — todos los caracteres especiales
- **Ctrl+C programatico NO funciona con AnyDesk** — VK codes, UNICODE U+0003, todos se renderizan como texto
- **Screenshot base64 en response** causa timeout de 2-3 min en Claude Desktop — resuelto con save_to_disk por defecto
